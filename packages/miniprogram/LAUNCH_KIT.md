## 1. 隐私协议全文

**操作位置**：mp.weixin.qq.com → 设置 → 服务内容声明 → 用户隐私保护指引 → 新建

**填写方式**：先把下方"信息收集清单"逐项添加，"第三方 SDK 清单"按实际情况勾选微信自带能力；最后把"用户协议正文"整段贴到自定义文本框。

### 1.1 信息收集清单（逐项添加）

| 信息类型 | 用途 | 使用场景 |
|---|---|---|
| 微信昵称 | 展示在你的 AI 名片上，让访客认出你 | 用户主动编辑名片时 |
| 头像 | 展示在名片头像位，由用户主动选择 | 用户主动选择图片时 |
| 图片/视频（相册或拍摄） | 用作自定义头像 | 用户点击"自定义头像"按钮时 |
| 聊天文本内容 | 与你的 AI 分身对话，记住你确认过的内容用于个性化 | 用户主动与 Vibe 对话时 |
| 设备标识 / openid | 区分用户身份，保证只有你自己能看到你的私有数据 | 用户登录时自动获取 |
| 本地缓存（storage） | 记住名片草稿、设置，离线时也能用 | 全程自动 |
| 剪贴板 | 一键复制分享口令 | 用户点击"复制分享"按钮时（如有） |

### 1.2 用户隐私保护指引（正文）

```
VibeCard 用户隐私保护指引

更新日期：2026 年 8 月 17 日
生效日期：2026 年 8 月 17 日

我们（"VibeCard"）非常重视用户隐私。本指引说明我们在 VibeCard
微信小程序（以下简称"本小程序"）中如何收集、使用、存储、保护你的
个人信息。

一、我们收集的信息

1. 微信昵称、头像：仅在你主动编辑名片或上传头像时使用，用于在你的
   AI 名片上展示。你拒绝提供不会影响小程序其它功能的使用。
2. 你与 AI 分身的聊天文本：仅在你主动发起对话时收集。AI 会基于这些
   内容生成记忆"提议"，但只有在你显式点击"记住"之后，内容才会被
   长期保存；你拒绝的提议会被立刻删除且永不检索。
3. 图片/视频：仅在你点击"自定义头像"按钮并主动选择时上传一次，用作
   你的名片头像。我们不会读取你相册中的其它内容。
4. 设备标识与 openid：微信登录时自动获取，用于识别你是名片主人还是
   访客，确保私有数据只对主人可见。
5. 本地缓存：保存在你的设备上，用于离线时也能查看名片。清除小程序
   数据即可删除。
6. 剪贴板：仅在你点击"复制分享"按钮时写入一次分享口令，不会自动
   读取你的剪贴板。

二、我们如何使用信息

- 提供 AI 名片、AI 对话、连接请求等本小程序的核心功能。
- 永远不会用于向你推送广告，永远不会出售给第三方。

三、信息的存储与共享

- 你的数据存储在腾讯微信云开发平台上，加密传输。
- 你的联系方式（微信、电话等）默认完全私有，只有在主人主动点击
  "通过连接"之后，才会对被通过的访客可见一次。
- 我们不会与任何第三方共享你的可识别个人信息，法律要求除外。

四、你的权利

- 查看与导出：你可在"我的名片"中随时查看你的全部数据。
- 删除：你可随时删除单条记忆、整张名片、或通过清除小程序数据删除
  所有本地缓存；云端数据可通过"反馈与建议"联系我们删除。
- 撤回授权：你可以在微信 → 设置 → 隐私 → 授权管理中撤销授权。

五、信息安全

- 所有传输使用 HTTPS。
- AI 服务商（如 OpenAI / Anthropic 等）作为受托处理方，仅在为生成
  回复所必需的最短时间内处理你的对话文本，不用于训练，不长期保存。

六、未成年人保护

- 本小程序不面向 13 岁以下未成年人。如果我们发现未经监护人同意
  收集了未成年人个人信息，将立即删除。

七、联系我们

- 如对本指引有任何疑问，可通过小程序内"反馈与建议"联系我们，
  或发送邮件至：privacy@vibecard.example
  （注：此为占位邮箱，上线前请替换为你真实的隐私联系邮箱）

八、本指引的更新

- 我们可能适时修订本指引。更新后的指引一经公布即替代旧版本。
```

> ⚠️ 上线前必须做的两件事：
> 1. 把第八节里的 `privacy@vibecard.example` 替换为你真实的邮箱。
> 2. 信息收集清单中如果你启用了"复制分享口令"功能才勾选剪贴板；没启用就不要勾。

## 2. 订阅消息模板申请文案

**操作位置**：mp.weixin.qq.com → 功能 → 订阅消息 → 我的模板 → 从公共模板库选用 / 申请新模板

### 2.1 模板一：主人收到新连接请求（`OWNER_NEW_REQUEST`）

**申请路径**：公共模板库搜索「社交 / 求职 / 招募」分类，找「新的申请通知」类模板；如果没有合适的，点"申请新模板"按下面内容填。

**关键字段填写**：

```
模板标题：新的认识请求
模板描述：当有访客通过你的 AI 分身向你发送认识请求时，通知你及时查看。
所属行业：IT科技 / 互联网 / 电子商务（或"工具"）
场景说明：用户把 AI 名片分享出去后，访客通过 AI 分身聊完后可以发送
一条具体的"认识请求"。本模板用于在主人未打开小程序时通知其有新请求，
帮助主人在 24 小时内做出回应，避免错过潜在的连接机会。
发送方：VibeCard 小程序（wxa79d41c8255ff90d）
接收方：名片主人
```

**正文示例**（按微信标准字段填，最多 5 行）：

```
{{visitorSummary.DATA}}
理由：{{reasonSummary.DATA}}
共同点：{{sharedContext.DATA}}
时间：{{dateTime.DATA}}
点击查看 → {{jumpUrl.DATA}}
```

**字段说明**（每个字段后面要填"示例"）：

- `visitorSummary`：示例 `一位独立开发者`；类型 `字符串`
- `reasonSummary`：示例 `他在做一个 AI 记账小程序，刚好遇到我正在思考的私有记忆边界问题`；类型 `字符串`
- `sharedContext`：示例 `都在做 AI 产品 / 都关心隐私设计`；类型 `字符串`
- `dateTime`：示例 `2026-08-17 16:30`；类型 `日期`
- `jumpUrl`：示例 `/pages/requests/requests`；类型 `链接`

**申请通过后**：把拿到的真实模板 ID（形如 `9w7v8KxxxxxXxxxxXXxXXXxXxxxXXXX`）复制到 `packages/miniprogram/miniprogram/utils/subscribe.js` 中：

```js
const TMPL = {
  OWNER_NEW_REQUEST: '把这里替换成真实的 tmplId',  // ← 替换
  ...
};
```

### 2.2 模板二：访客收到请求通过通知（`VISITOR_REQUEST_ACCEPTED`）

**申请路径**：同上，公共模板库搜索「审核通过」类模板；或申请新模板。

**关键字段填写**：

```
模板标题：你的认识请求已通过
模板描述：当名片主人通过了你提交的认识请求时，通知你查看主人选择的联系方式。
所属行业：同上
场景说明：访客提交认识请求后通常需要等待。本模板用于在主人通过请求时
第一时间通知访客，访客可以看到主人选择分享的联系方式，完成握手。
发送方：同上
接收方：访客（提交请求的用户）
```

**正文示例**：

```
你好 {{visitorName.DATA}}，
{{ownerName.DATA}} 已经通过了你的认识请求。
联系方式：{{contactHint.DATA}}
时间：{{dateTime.DATA}}
```

**字段说明**：

- `visitorName`：示例 `苏晴`；类型 `字符串`
- `ownerName`：示例 `林舟`；类型 `字符串`
- `contactHint`：示例 `已选择 1 种联系方式（详情见小程序）`；类型 `字符串`
  （**安全提醒**：模板里只放提示文案，不放真实联系方式值，防止截图泄露）
- `dateTime`：示例 `2026-08-17 17:00`；类型 `日期`

**申请通过后**：同样把真实 tmplId 替换到 `subscribe.js` 的 `VISITOR_REQUEST_ACCEPTED`。

## 3. 云函数部署脚本

**操作位置**：在本地终端执行（不需要进 DevTools）。

### 3.1 安装微信小程序 CLI（如果还没装）

```bash
npm install -g miniprogram-ci
```

### 3.2 创建部署脚本

在 `packages/miniprogram/` 目录下创建 `deploy/deploy-cloud.js`：

```js
const ci = require('miniprogram-ci');
const path = require('path');

const PROJECT = new ci.Project({
  appid: 'wxa79d41c8255ff90d',
  type: 'miniProgram',
  projectPath: path.join(__dirname, '..'),
  privateKeyPath: process.env.MP_PRIVATE_KEY,  // 微信公众平台 → 开发管理 → 开发设置 → 小程序代码上传密钥
  ignores: ['node_modules/**/*'],
});

const FUNCTIONS = [
  'agent', 'card', 'memory', 'now', 'requests',
  'user', 'login', 'content-check', 'report',
];

(async () => {
  for (const name of FUNCTIONS) {
    console.log(`\n=== 上传云函数 ${name} ===`);
    await ci.cloud.deployFunction({
      project: PROJECT,
      name,
      path: path.join(__dirname, '..', 'cloudfunctions', name),
      remoteNpmInstall: true,
    });
    console.log(`✅ ${name} 上传成功`);
  }
  console.log('\n🎉 全部云函数部署完成');
})();
```

### 3.3 一键部署命令

```bash
# 1. 下载小程序代码上传密钥（在 mp.weixin.qq.com → 开发管理 → 开发设置）
# 2. 把下载的 .key 文件保存到本地，然后：
export MP_PRIVATE_KEY=/path/to/your/private.key

# 3. 在 packages/miniprogram 下执行：
cd /Users/fangchen/Baidu/GitHub/VibeCard/packages/miniprogram
node deploy/deploy-cloud.js
```

> ⚠️ 首次部署每个云函数时，微信会自动创建对应的函数实例；不需要手动在控制台建。

## 4. 数据库集合 + 索引清单

**操作位置**：微信开发者工具 → 云开发 → 数据库 → +

### 4.1 集合清单（9 个，按下面顺序创建）

| 集合名 | 用途 | 权限设置 |
|---|---|---|
| `users` | 用户档案 + 主人联系方式 + 黑名单 | 仅创建者可读写 |
| `memories` | 记忆（提议 / 已确认 / 已删除） | 仅创建者可读写 |
| `conversations` | 对话历史 | 仅创建者可读写 |
| `requests` | 连接请求 | 仅创建者可读写 |
| `now_items` | 主人最近动态（公开） | 所有用户可读，仅创建者可写 |
| `visitor_activity` | 访客活动计数（限流用） | 仅创建者可读写 |
| `reports` | 用户举报记录 | 仅创建者可读写 |
| `blocks` | 黑名单（如单独建表） | 仅创建者可读写 |
| `audit_logs` | 审核 / 安全日志 | 仅创建者可读写 |

> 上面"权限"列是默认推荐；个别字段（如 `requests` 的 `decision`）由云函数代主人更新，所以实际权限都是"仅创建者可读写"，所有跨用户写入都通过云函数走。

### 4.2 索引清单（在每个集合的"索引管理"里添加）

```
集合：memories
  索引 1：  字段 ownerId (正序) + status (正序) + visibility (正序)
  索引 2：  字段 ownerId (正序) + updatedAt (倒序)

集合：requests
  索引 1：  字段 ownerId (正序) + status (正序) + createdAt (倒序)
  索引 2：  字段 visitorId (正序) + ownerId (正序) + createdAt (倒序)

集合：now_items
  索引 1：  字段 ownerId (正序) + status (正序) + publishedAt (倒序)

集合：conversations
  索引 1：  字段 ownerId (正序) + updatedAt (倒序)

集合：visitor_activity
  索引 1：  字段 _id (主键，自动存在)
            _id 格式约定：visitorId:ownerId:YYYY-MM-DD（East-8 日期）
```

## 5. 提审备注

**操作位置**：上传代码后，mp.weixin.qq.com → 管理 → 版本管理 → 提交审核

把下面整段复制到"备注"输入框：

```
VibeCard 是一张「会越来越懂你」的 AI 名片。本小程序不涉及支付、
不涉及直播、不涉及 UGC 公开发布，所有用户内容都是私聊性质或
点对点的认识请求。

【审核测试路径】

1. 主人视角（账号 A）：
   - 登录后点底部「名片」Tab → 完善资料 → 点「Vibe」Tab →
     与 AI 分身对话一句（例如："我最近在做 VibeCard"）→
     AI 会提议一条记忆，点「记住」→ 回到「名片」可以看到自己。

2. 访客视角（账号 B）：
   - 通过账号 A 分享的小程序卡片进入 → 看到名片 →
     点「先和我的 Vibe 聊聊」→ 与 AI 分身对话 → 提交一条
     「认识请求」（理由至少 10 个字）。

3. 主人处理请求（回到账号 A）：
   - 点底部「请求」Tab → 看到刚才的请求 → AI 的「看法」→
     点「认识一下」→ 选择一种联系方式 → 双方看到「Vibe matched」。

【内容安全说明】

- 访客提交的所有文本（姓名、理由）都会通过 wx.content-security
  云函数审核，审核失败的请求会被拦截（不会出现在主人 inbox 里）。
- AI 分身明确声明自己是 AI（开场白第一句："我是 TA 的 AI 分身"）。
- 所有联系方式默认私有，只有主人主动点击「认识一下」之后才会对
  通过的访客可见。

【隐私合规说明】

- 已开启 __usePrivacyCheck__，冷启动会弹出微信标准隐私授权框。
- 已在「设置 → 服务内容声明 → 用户隐私保护指引」提交协议并通过。
- 仅使用 chooseMedia、本地 storage、订阅消息 三项用户授权，
  无定位、无通讯录、无手机号、无相机预览。

【订阅消息说明】

- 在访客「提交请求」和主人「通过连接」两个时机请求订阅授权，
  用于发送「新认识请求到达」与「请求已通过」通知。
  模板 ID 已配置在 utils/subscribe.js（如尚未配置，会在控制台
  打印警告，不影响主流程）。

【账号】

如审核员需要预置测试数据，可直接登录任意账号，小程序会自动
初始化。所有云函数已部署到 wxa79d41c8255ff90d 的云开发环境。

如有任何问题，请联系：support@vibecard.example
（占位邮箱，上线前替换为真实联系方式）
```

## 6. 真机演示路径（提审附录）

打印一份或截图存手机，审核或现场演示时按这个顺序点：

```
账号 A（主人）：

1. 打开小程序 → 同意隐私协议弹窗（冷启动一次）
2. 点「名片」Tab → 上滑进入「编辑」→ 填名字「测试主人」
   → 选一个标签「Builder」→ 保存
3. 切到「Vibe」Tab → 输入：「我最近在做一张 AI 名片」
   → AI 回复后会弹出"记住"提议 → 点「记住」
   → 顶部出现「我记住了：我最近在做一张 AI 名片」
4. 点右上角 ⋯ → 「分享给朋友」→ 发给账号 B

──────────────────────────────────────

账号 B（访客）：

5. 收到分享卡片点开 → 看到主人的名片
6. 点「先和我的 Vibe 聊聊」→ 输入「他在做什么？」
   → AI 回复（基于主人公开的记忆）
7. AI 引导提交请求 → 输入理由（至少 10 个字，例如：
   「我也是独立开发者，正在思考 AI 产品的隐私边界」）
   → 点「提交」→ 弹出订阅消息授权框 → 选择「允许」
   → 显示「已送达」

──────────────────────────────────────

账号 A（回到主人）：

8. 切到「请求」Tab → 看到刚收到的请求 → 点进去
   → 看到 AI 的看法（基于证据的"值得聊一次"或"信息不够"）
9. 点「认识一下」→ 勾选「微信」→ 确认
   → 弹出订阅授权框（通知访客）→ 选择「允许」
   → 双方看到「Vibe matched」+ 主人选择的联系方式
10. 账号 B 会收到订阅消息 → 点开 → 看到联系方式提示

✅ 演示完成
```

## 9. 卡住时怎么办

- **隐私协议被驳回**：通常是"信息收集清单"跟正文对不上。检查每一项是否一一对应。
- **订阅模板被驳回**：行业分类选错了；社交类模板要走"社交"行业，求职类要走"工具"。
- **云函数部署失败**：确认 `MP_PRIVATE_KEY` 环境变量指向了正确的 `.key` 文件路径。
- **真机白屏**：检查 `app.json` 的 `__usePrivacyCheck__` 是否正确，隐私弹窗没通过会卡死。
- **订阅消息不弹**：检查模板 ID 是否替换为真实 ID（占位 ID 会触发安全降级，不弹窗）。
- **提审被拒 - "AI 类目资质"**：如果你申请了"AI 服务"类目但没有算法备案，改用"工具"或"社交"类目。
