## 一、云端准备（约 10 分钟）

### 1.1 部署云函数

在微信开发者工具中打开 `packages/miniprogram`，逐个右键「上传并部署：云端安装依赖」：

- [ ] `login`
- [ ] `user`
- [ ] `agent`
- [ ] `card`
- [ ] `memory`
- [ ] `now`（4.5 新增，**必须部署**，否则云端 Now 不可用）
- [ ] `requests`
- [ ] `content-check`
- [ ] `report`

### 1.2 创建数据库集合与索引

云开发控制台 → 数据库：

- [ ] 确认集合存在：`users` / `memories` / `now_items` / `conversations` / `requests` / `visitor_activity` / `visitor_evidence` / `request_gates` / `reports`（不存在则手动创建）
- [ ] `now_items` 索引一：`ownerId` 升序 + `status` 升序 + `publishedAt` 降序
- [ ] `now_items` 索引二：`ownerId` 升序 + `expiresAt` 升序
- [ ] 索引说明见 `packages/miniprogram/cloudfunctions/now/README.md`
- [ ] `visitor_evidence`：`ownerId + visitorId` 普通索引，并为 `expiresAt` 配置 24 小时 TTL；请求成功后记录也会立即删除
- [ ] `request_gates`：确认集合存在；仅使用自动 `_id` 主键，不需要手动复合索引

### 1.3 模型配置（云端模式）

- [ ] `agent` 云函数环境变量按 `docs/engineering/MODEL_ADAPTERS.md` 配置（`AI_PROVIDER` / `AI_API_BASE` / `AI_MODEL` / `AI_API_KEY`）
- [ ] 未配置时确认 agent 回退到 deterministic mock，对话不报错

## 三、4.2 真机验证（Card / 头像 / 分享）

### 3.1 Owner 路径

- [ ] 微信登录成功，进入「我的 Card」
- [ ] 头像选择器：从相册选择/拍照上传头像，Card 上正确显示
- [ ] 标签网格选择正常（多选、取消、保存后刷新仍在）
- [ ] 编辑 Card 各字段并保存，返回后内容一致

### 3.2 分享链路（重点，至少一台真实设备）

- [ ] 点击分享 → 生成分享卡片图（人物优先设计，无推广元素）
- [ ] 分享给微信好友/群，对方收到的小程序卡片标题、头像图正常
- [ ] **另一台设备（或让朋友）点开分享卡片** → 打开的是正确的 Owner 的 Card（不是自己的、不是空白）
- [ ] 朋友圈海报/二维码路径（如有）保存图片成功
- [ ] 短链接/复制路径在聊天中可正常打开

### 3.3 Visitor 路径

- [ ] 访客在分享 Card 上看到「先和我的分身聊聊」入口
- [ ] 进入访客对话，分身自我声明为 AI 分身
- [ ] 提问 Card 上有的内容，回答有依据；问没有的内容，明确说不知道
- [ ] 索取联系方式被拒绝，引导留连接理由
- [ ] 提交一条具体连接理由 → Owner 的「联系请求」中可见
- [ ] Owner 选择「认识一下」并选择联系方式 → 显示 Vibe matched；访客端看到联系方式
- [ ] 举报与拉黑后，被拉黑访客无法再发起对话/请求

## 四、4.5 真机验证（个人 Now 动态）

### 4.1 Owner 管理（云端模式）

- [ ] 「我的 Vibe」页面出现「最近动态」管理入口
- [ ] 手动写一条 Now 并发布 → 「我的 Card」的「最近动态」区出现该条
- [ ] 再发布两条以上 → Card 最多只显示最新 3 条
- [ ] 编辑一条已发布 Now，Card 上内容同步更新
- [ ] 归档一条 → 它从 Card 公开区消失（管理面板仍可见，标记已归档）
- [ ] 隐藏一条 → 同样不再公开显示
- [ ] 删除一条 → 管理与公开视图中均消失

### 4.2 Vibe 提议（不得自动发布）

- [ ] 和 My Vibe 聊一件「最近在做的事」→ Vibe 提出 Now 草稿卡片
- [ ] 未经确认前，公开 Card 上**不出现**该内容
- [ ] 点「改一下」修改后发布 → 公开 Card 显示修改后的版本
- [ ] 点「先不了」→ 草稿不发布、不出现在公开区

### 4.3 访客侧 grounding

- [ ] 访客问「他最近在做什么？」→ 分身只引用已发布、未过期的 Now 内容
- [ ] 归档/隐藏/删除/过期后的内容，分身不再当作近期事实引用
- [ ] Owner 无任何公开 Now 时，分身明确说「他最近还没有公开动态」，不编造
- [ ] 私人聊天中的原话不会未经确认出现在公开回答里

### 4.4 双模式

- [ ] 断网或云函数不可达时，fixture 演示模式仍可完整走通（Card 展示与分身回答使用演示数据）
- [ ] 恢复网络后云端模式数据与操作正常
